# Legacy scripts — provenance only, do not run

These scripts produced the Lauderdale BAM files that every published count
matrix was built from. They were written before the manifest-driven pipeline in
`pipeline/` and are kept only so that the published BAMs can be traced to the
code that made them.

Do not run them. Their known problems are listed below. None of these
problems affects the published results, for the reasons given.

| Script | Produced | Known problems |
|---|---|---|
| `fastqc_trimming_..._NOVOGENE_X202SC.sh` | 2026 trimmed reads | Post-trimming FastQC ran on R1 only. Trimming parameters are the same as `qc_trim_batch.sh`. |
| `HISAT2_..._PATCH_2.sh` | 2026 BAMs (job 46769402) | Tool versions resolved at run time, not pinned. Its featureCounts step (`-p -s 2`, no `--countReadPairs`) and StringTie step (`--rf`) were wrong for these unstranded libraries. Neither output is used: counts were regenerated by `count_study.sh`, and the StringTie/prepDE outputs were deleted. |

The 2025 batch was aligned with the same GRCm38 `genome_snp_tran` index and
GENCODE vM25 annotation (job log `HISAT2_Mouse_RNAseq_38507686.out`, July
2025). That script did not record tool versions.
